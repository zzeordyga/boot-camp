# Assignment 11 – Task Management App with Next.js

**Ishvara Pranidhana Lakshmana · 2602181004**

A task manager built with Next.js and Firebase Firestore. Can create, edit, complete and delete tasks, and every open tab updates in real time. Sort order and filter are remembered in localStorage, theme and language are global settings shared through the Context API, and the main logic is covered by Jest and Testing Library tests.
