# Pokédex – Take-Home React & Next.js

Halaman Next.js (App Router) dengan layout, nested route, integrasi PokeAPI, dan hooks.

- `/2602180802` – daftar 151 Pokémon (search, sort, filter favorit, load more)
- `/2602180802/details?name=pikachu` – detail Pokémon (stats, abilities, suara)

Hooks: useState, useEffect, useRef, useMemo (+ custom hook `useFavorites`).
